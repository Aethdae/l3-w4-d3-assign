# Small To-do App

## Installation

- `npm i` to get dependencies

- add .env containing a supabase table "todos" with schema:
  - id `int8 primary key`
  - todo `text`
  - severity `text`
  - created_at `timestamptz`
- Alternatively:
  ```sql
  CREATE TABLE todos(
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY NOT NULL,
  created_at timestamptz DEFAULT now() NOT NULL,
  severity text NOT NULL,
  todo text NOT NULL
  )
  ```

## Usage

`npm run dev` to run the app

Add a to-do with the form at the top, and it will render along the page as you add more.
Click Remove to get rid of any completed todos.
